## 📘 About the App
**The Unarchiver** helps macOS users quickly open and extract a wide range of archive formats with Finder integration and simple defaults.  
It supports features like **drag-and-drop**, **context menu (“Open With…”)**, automatic extraction folders, and broad format compatibility.

This guide focuses on **legal distribution channels** (official website, verified package managers like Homebrew) and **does not host binaries** in this repository.

---

## 🧭 Quick Start (Usage)

* **Extract an archive**: Double-click the file (e.g., `.zip`, `.rar`, `.7z`) or right-click → **Open With** → **The Unarchiver**.
* **Set as default**: Right-click an archive → **Get Info** → **Open with:** The Unarchiver → **Change All…**.
* **Choose extraction folder**: Open The Unarchiver → **Preferences** → **Extraction** → set destination (e.g., “Same folder”, “Desktop”, etc.).
* **Handle passwords**: For password-protected archives, enter the correct password when prompted.
* **Keep or delete archives** after extraction: Adjust in **Preferences → Extraction**.

## ⚙️ System Requirements

* **Operating System:** macOS 10.13 High Sierra or newer (Intel or Apple Silicon)
* **CPU:** Intel x86_64 or Apple M-series
* **Memory:** 2 GB RAM or more
* **Disk:** ~200 MB free (app + working space for archives)
* **Network:** Required to fetch from official sources

## 💡 Tips & Tricks

* Prefer the **Homebrew cask** for repeatable installs across machines.
* **Verify downloads** with SHA-256 when the vendor provides checksums.
* Use **Finder’s context menu** for quick extraction without opening the app.
* Keep both **macOS** and **The Unarchiver** updated for the best compatibility.
